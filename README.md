## Current work

### [AtomMail](https://github.com/awhite0030/atommail)

Disposable email service with zero registration and no data retention. Implemented on Cloudflare Workers and Email Routing for edge performance and privacy by design.

### [ERouter](https://github.com/awhite0030/ERouter)

Open-source AI request router and token optimizer. Provides a unified OpenAI-compatible endpoint across 40+ providers with automatic fallback, rate-limit handling, and observability.

### [smm-support-bot](https://github.com/awhite0030/smm-support-bot)

Telegram support platform with topic isolation, anti-spam, Redis-backed state, and SLA automation. Built for high-volume operational workflows.
