## Current work

### [AtomMail](https://github.com/awhite0030/atommail)

Disposable email in minutes. No sign-up, no tracking, no persistence. Built entirely on Cloudflare Workers + Email Routing. Zero friction, pure privacy.

### [ERouter](https://github.com/awhite0030/ERouter)

Open-source AI router & token saver. Connect Claude Code, Cursor, Codex and other tools to 40+ providers with auto-fallback, RTK and a clean dashboard.

### [smm-support-bot](https://github.com/awhite0030/smm-support-bot)

Telegram support workflow bot with topics, anti-spam, Redis state and SLA automation. Designed for high-volume support teams.
